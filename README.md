# Бюропереводчик

**Из проблемы — в понятное действие.**

Сервис превращает обычное описание бытовой проблемы в официальный черновик обращения, персональный план действий и список того, что стоит проверить перед отправкой.

## Быстрый запуск

### Windows
1. Откройте [репозиторий](https://github.com/SMisha2/hackaton_gpt) и нажмите **Code → Download ZIP**.
2. Распакуйте архив.
3. Дважды нажмите `START.bat` и выберите первый вариант. Для обычного запуска ничего устанавливать не требуется.

Можно открыть `index.html` напрямую, но без локального HTTP-сервера будут недоступны PWA и серверные функции.

### macOS / Linux
Распакуйте ZIP и запустите `./start.sh`. Для режима разработки с API используйте `./start.sh dev`.

## Возможности
- Шесть категорий бытовых ситуаций.
- Подсказки, примеры и поля дополнительного контекста.
- Локальное преобразование эмоциональных фраз в нейтральный стиль.
- Шаблон обращения с адресатом, фактами, просьбой и приложениями.
- Специфические подсказки и план действий в зависимости от категории и описания.
- Редактирование, копирование, скачивание TXT и печать / сохранение в PDF.
- Явное согласие перед передачей данных в ИИ-режим.
- Светлая и тёмная темы.
- PWA-оболочка с офлайн-кешем интерфейса.
- Автоматические тесты и проверка синтаксиса через GitHub Actions.

## Публикация

### GitHub Pages
Статическая версия публикуется workflow-файлом `.github/workflows/pages.yml`. В настройках репозитория выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. После этого изменения фронтенда в `main` будут публиковаться автоматически.

GitHub Pages запускает фронтенд и локальный генератор. Серверный ИИ-режим на Pages не работает.

### Vercel с ИИ
Импортируйте репозиторий по ссылке [Deploy on Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FSMisha2%2Fhackaton_gpt). Добавьте `OPENAI_API_KEY` как серверную переменную окружения и нажмите Deploy. При необходимости задайте `OPENAI_MODEL`; по умолчанию используется `gpt-6.2-sol`.

## Разработка
Требуется Node.js 20+:
```bash
npm test
npm run check
```

## Приватность
Локальный режим не отправляет введённое описание в сеть и не сохраняет его приложением. В ИИ-режиме текст и дополнительные поля передаются серверу проекта и внешнему ИИ-провайдеру только после отдельного согласия. Не вводите пароли, паспортные или банковские данные.

Сервис готовит информационный черновик, а не юридическое заключение. Проверяйте адресата, даты, факты, применимые правила и список приложений. Не отправляйте документ, пока не заменили поля в квадратных скобках.
