# Бюрократический переводчик

**Проблема есть. Слова найдутся.**

Веб-сервис превращает описание бытовой проблемы в структурированный черновик официального обращения и понятный план следующих действий.

## Запустить за минуту

### Windows

1. Нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив.
2. Дважды щёлкните `START.bat`.
3. Выберите **1 — открыть сайт**. Ничего устанавливать не нужно.

Можно также сразу открыть `index.html` двойным щелчком.

### macOS / Linux

1. Скачайте ZIP-архив репозитория и распакуйте его.
2. Откройте `index.html` в браузере.

Для локального запуска серверных API-функций нужен Node.js 20+ и вход в Vercel CLI:

```bash
npm run dev
```

В Windows этот режим доступен в `START.bat`, вариант 2.

## Опубликовать сайт

### GitHub Pages — статическая версия

1. Откройте [Settings → Pages](https://github.com/SMisha2/hackaton_gpt/settings/pages).
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Сохраните настройки. Дальнейшие обновления `main` будут публиковаться автоматически.

Если Pages ещё не включены, workflow пропустит деплой и покажет подсказку. Включение требует ручного подтверждения владельца репозитория.
4. Адрес сайта: `https://smisha2.github.io/hackaton_gpt/`.

На GitHub Pages работает статический интерфейс и локальный генератор. Серверный ИИ-режим там недоступен.

### Vercel — версия с ИИ API

[**Развернуть проект на Vercel ↗**](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FSMisha2%2Fhackaton_gpt)

1. Импортируйте репозиторий.
2. В настройках Vercel добавьте серверную переменную `OPENAI_API_KEY`.
3. При необходимости задайте `OPENAI_MODEL`; значение по умолчанию — `gpt-6.2-sol`.
4. Нажмите **Deploy**.

Без ключа проект работает в локальном режиме. Никогда не добавляйте API-ключ в HTML, JavaScript или GitHub.

## Возможности

- Категории: ЖКХ, покупки и услуги, работа, городская среда, доставка и другие ситуации.
- Контекст: дата, желаемый результат, предыдущие обращения и подтверждения.
- Локальный режим и отдельный ИИ-режим с предупреждением перед передачей данных.
- Редактирование документа, копирование, скачивание TXT и печать / сохранение в PDF.
- Персональный план действий с чек-листом.
- Проверка адресата, дат, фактов и приложений.
- Адаптивный интерфейс, очистка формы одним нажатием.
- Устанавливаемая оболочка и офлайн-кеш на поддерживаемых браузерах.

## Разработка и тесты

Требуется Node.js 20+:

```bash
npm test
npm run check
npm run dev
```

GitHub Actions автоматически запускает тесты и проверку синтаксиса после каждого push и pull request.

## Конфиденциальность и ограничения

Локальный режим не отправляет пользовательские сведения в сеть и не сохраняет их приложением. При включении ИИ-режима описание и заполненные поля передаются серверу проекта и внешнему ИИ-провайдеру. Не добавляйте пароли, паспортные или банковские данные.

Сервис создаёт информационный черновик, а не юридическое заключение. Перед отправкой проверьте адресата, даты, факты, применимые правила и приложения. Модель не должна выдумывать нормы, сроки и ссылки.
