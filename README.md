# Бюрократический переводчик

**Проблема есть. Слова найдутся.**

Веб-сервис превращает описание бытовой проблемы в структурированный черновик официального обращения и понятный план следующих действий.

## Возможности

- Категории: ЖКХ, покупки и услуги, работа, городская среда, доставка и другие ситуации.
- Контекст: дата, желаемый результат, предыдущие обращения и имеющиеся доказательства.
- Локальный режим без отправки пользовательского текста в сеть.
- Опциональный ИИ-режим через серверную функцию. Включается пользователем отдельно после предупреждения о передаче данных.
- Редактирование документа, копирование, скачивание TXT и печать / сохранение в PDF.
- Персональный чек-лист с прогрессом выполнения.
- Блок проверки адресата, дат, фактов и приложений.
- Адаптивный интерфейс.

## Запуск локальной версии

Откройте `index.html` в современном браузере. Локальный режим не требует установки пакетов.

## ИИ-режим

ИИ-режим реализован через серверные функции Vercel и OpenAI Responses API. Сам ключ нельзя помещать в HTML или JavaScript браузера.

1. Разверните репозиторий на Vercel (папка `api/` автоматически содержит serverless functions).
2. В настройках проекта Vercel добавьте переменную окружения `OPENAI_API_KEY`.
3. При необходимости задайте `OPENAI_MODEL`; по умолчанию используется `gpt-6.2-sol`.
4. Выполните новый deployment после добавления переменных.

Без `OPENAI_API_KEY` сайт продолжит работать в локальном режиме. API-ключ должен настраивать уполномоченный владелец проекта в защищённых настройках хостинга. Не отправляйте секреты в GitHub и не вставляйте их в браузер. Серверный обработчик ограничивает входные данные и применяет простой лимит запросов на один экземпляр функции; перед публичным запуском дополнительно настройте распределённое ограничение частоты на уровне хостинга.

## Ограничения и безопасность

Сервис создаёт информационный черновик, а не юридическое заключение. Модель должна отделять факты из описания от предположений, не выдумывать статьи законов, сроки и адресатов, а спорные моменты оставлять на проверку. Перед отправкой проверьте документ самостоятельно.

Локальный режим не отправляет пользовательские сведения на сервер. В ИИ-режиме описание и указанные поля передаются серверу проекта и внешнему ИИ-провайдеру для генерации. Приложение не сохраняет тексты обращений намеренно и не обещает режим хранения данных провайдера. Не вводите пароли, паспортные и банковские данные.
