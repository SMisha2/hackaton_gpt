# Бюрократический переводчик

Веб-сервис, который помогает превратить эмоциональное описание бытовой проблемы в структурированное официальное обращение и понятный план дальнейших действий.

## MVP

- Форма для описания ситуации и выбора адресата.
- Генерация редактируемого черновика обращения.
- Персональный чек-лист следующих действий.
- Копирование текста и скачивание документа.
- Локальная работа без передачи введённых данных на сервер.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Важно

Сервис формирует информационный шаблон, а не юридическое заключение. Перед отправкой проверьте факты, адресата, сроки и применимые нормы. Не добавляйте в форму пароли, паспортные и банковские данные.
