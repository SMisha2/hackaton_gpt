# Бюрократический переводчик

**Проблема есть. Слова найдутся.**

Веб-сервис превращает описание бытовой проблемы в структурированный черновик официального обращения и понятный план следующих действий.

## Возможности MVP

- Категории: ЖКХ, покупки и услуги, работа, городская среда, доставка и другие ситуации.
- Поля для адресата, населённого пункта, даты и желаемого результата.
- Генерация структурированного обращения с аккуратными формулировками.
- Персональный чек-лист с отметками выполнения и прогрессом.
- Редактирование текста, копирование и скачивание в TXT.
- Адаптивная версия для мобильных устройств.
- Локальная обработка: введённый текст не отправляется на сервер и не сохраняется приложением.

## Запуск

Откройте \`index.html\` в современном браузере. Сборка и установка зависимостей не требуются.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку \`main\` и папку \`/(root)\`. После сохранения GitHub Pages опубликует сайт.

## Текущий режим генерации

В этой версии используется локальный генератор на правилах и шаблонах. Это позволяет протестировать интерфейс без API-ключа и не передавать личные сведения внешнему сервису. Он не является языковой моделью и не заменяет юридическую проверку.

## Следующий этап

Для полноценного AI-переводчика подключить серверный API-слой: отправлять на модель только необходимые сведения, не хранить обращения без согласия пользователя, проверять фактические утверждения и не генерировать неподтверждённые ссылки на законы, сроки или адресатов.

## Важно

Сервис формирует информационный черновик, а не юридическое заключение. Перед отправкой пользователь должен проверить факты, адресата, контактные данные, приложенные доказательства и применимые правила. Не вводите пароли, паспортные или банковские данные.
